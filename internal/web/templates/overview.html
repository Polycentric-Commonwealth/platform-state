How this State is verified

This State signs every record it sends with a key that {{.Parent}} has vouched for. Each record is added to the State's public ledger, which independent witnesses check and timestamp, so no record can be changed or backdated without it showing.

Every count is also audited: the State commits in advance to the list of people it counted, and the Commonwealth's Audit Office checks a random sample of them. See each period's audit.
